# test_docs_agent

Первый этап реализации тестового задания: извлечение структуры PDF и консервативное
определение связей между документами.

## Что уже реализовано

1. PDF parsing через PyMuPDF.
2. Извлечение ID вида `D123456789-01`.
3. Извлечение дат.
4. Определение типа документа.
5. Поиск явных ссылок одного документа на другой.
6. Построение графа связей.
7. Поиск connected components как кандидатов на историю одного договора.
8. Генерация базового Markdown-отчёта.

## Важное ограничение

Имя файла и имя папки НЕ считаются доказательством связи. Источником связи
служит явное упоминание идентификатора в тексте документа.

OCR пока вынесен в следующий этап: в выборке есть PDF со сканированным содержимым.

## Запуск

```bash
pip install -r requirements.txt
python scripts/analyze_dataset.py "/path/to/Задание_выборка"
pytest
```

Следующий этап: OCR fallback, более точное извлечение сущностей/ролей сторон,
версионирование условий и agent/LangGraph layer.
